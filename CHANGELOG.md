### Changed
- Migrasi arsitektur backend ke **Fastify (Node.js 20 LTS, TypeScript)** untuk mewujudkan Unified Full-Stack TypeScript Monorepo bersama Next.js 16 LTS (`ADR-001`).
- Penyesuaian integrasi AI ke **AWS Bedrock (Amazon Titan Text Express v1)** in-context extraction via SDK resmi v3 dengan mock deterministic fallback (`ADR-002`).
- Penyesuaian skema file storage menjadi pluggable (`STORAGE_BACKEND=local` / `s3`) (`ADR-003`).
- Pembaruan framework frontend ke **Next.js 16 (Active LTS)** dengan Turbopack stabil dan React 19 (`ADR-004`).
- Pemisahan parent folder frontend dan backend menjadi folder tingkat atas terpisah (`frontend/` dan `backend/`) dalam workspace pnpm monorepo.
